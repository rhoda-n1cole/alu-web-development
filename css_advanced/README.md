# CSS Advanced

This project transforms the semantic Smile School landing page from
`html_advanced` into a polished, responsive interface using plain CSS.
It follows the designer brief with a full-bleed hero, centered navigation,
purple quote and membership accents, video cards, FAQ grid, and a dark footer.

## What is included

- A complete copy of the advanced HTML page
- A single stylesheet imported from the document head
- Responsive layouts for desktop, tablet, and mobile screens
- Accessible alt text, keyboard-friendly links, and semantic section anchors
- No frameworks, build tools, or external JavaScript libraries
