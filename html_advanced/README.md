# HTML Advanced

This project is a semantic HTML implementation of a landing page based on a
designer specification. It intentionally uses HTML only: the page is divided
into meaningful header, main, section, article, and footer content so that
future CSS can style it without changing its structure.

## Page sections

- Header navigation and clickable logo
- Banner with a call to action and feature highlights
- Inspirational quote
- Video cards with authors and ratings
- Membership offers
- Frequently asked questions
- Footer branding and social links
